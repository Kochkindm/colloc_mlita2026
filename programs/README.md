# Библиотека аннотированных программ

## Назначение

Библиотека содержит функции из проекта второго семестра,
адаптированные для формальной верификации.

Для каждой функции подготовлены две версии:

- `correct.py` — корректная реализация;
- `broken.py` — реализация с намеренно внесённой ошибкой.

Обе версии имеют одинаковые аннотации.

Исходное представление чисел в виде объектов и списков цифр
заменено обычными целочисленными переменными для совместимости
с языком верификатора. Математическое назначение операций сохранено.

## 1. POZ_Z_D — определение знака целого числа

Исходный файл: `MODULES/Integer.py`.

### Назначение

Функция определяет знак целого числа и возвращает:

- 0 — число равно нулю;
- 1 — число отрицательное;
- 2 — число положительное.

### Предусловие

```python
# requires True
```

На вход допускается любое целое число.

### Постусловие

```python
# ensures (n == 0 and result == 0) or (n < 0 and result == 1) or (n > 0 and result == 2)
```

Возвращаемое значение должно соответствовать знаку входного числа.

### Инвариант

Отсутствует, так как адаптированная функция не содержит циклов.

### Намеренная ошибка

В сломанной версии для положительного числа возвращается 1 вместо 2.

### Контрпример

- Входные данные: n = 10.
- Ожидаемый результат: 2.
- Фактический результат: 1.
- Постусловие нарушено.

## 2. COM_NN_D — сравнение натуральных чисел

Исходный файл: `MODULES/Natural.py`.

### Назначение

Функция сравнивает два натуральных числа и возвращает:

- 0 — числа равны;
- 1 — первое число меньше второго;
- 2 — первое число больше второго.

В исходном проекте сравнение выполняется по количеству
цифр и значениям отдельных разрядов.

В адаптированной версии используются целочисленные
переменные, цикл while и целочисленное деление.
Младшие разряды последовательно отбрасываются,
пока сохраняется различие между числами.

### Предусловие

```python
# requires a >= 0 and b >= 0
```

Оба входных числа должны быть неотрицательными целыми.

### Постусловие

```python
# ensures (a == b and result == 0) or (a < b and result == 1) or (a > b and result == 2)
```

Возвращаемое значение должно соответствовать
результату сравнения исходных чисел.

### Инвариант

```python
# invariant x >= 0 and y >= 0 and ((a == b and x == y) or (a < b and x < y) or (a > b and x > y))
```

Инвариант гарантирует, что переменные x и y остаются
неотрицательными, а отношение между ними соответствует
отношению между исходными числами a и b.

Инвариант должен выполняться перед входом в цикл
и сохраняться после каждой итерации.

### Намеренная ошибка

В сломанной версии присваивание:

```python
x = x // 10
```

заменено на:

```python
x = y // 10
```

В результате переменные x и y становятся равными,
что приводит к нарушению инварианта.

### Контрпример

- Входные данные: a = 10, b = 20.
- До выполнения цикла: x = 10, y = 20.
- После ошибочной итерации: x = 2, y = 2.
- Ожидаемый результат: 1.
- Фактический результат: 0.
- Инвариант и постусловие нарушены.

### Ожидаемый результат верификации

| Версия | Вердикт |
| --- | --- |
| correct.py | Proved |
| broken.py | Failed |

## 3. NZER_N_B — проверка натурального числа на ненулевое значение

Исходный файл: `MODULES/Natural.py`.

### Назначение

Функция проверяет, является ли натуральное число ненулевым.

В исходном проекте функция возвращает строки «да» и «нет».
В адаптированной версии используются целочисленные значения:

- 0 — число равно нулю;
- 1 — число не равно нулю.

Это необходимо для совместимости с языком верификатора,
который не предусматривает строковые константы.

### Предусловие

```python
# requires n >= 0
```

На вход подаётся неотрицательное целое число.

### Постусловие

```python
# ensures (n == 0 and result == 0) or (n > 0 and result == 1)
```

Возвращаемое значение должно соответствовать результату
проверки числа на ненулевое значение.

### Инвариант

Отсутствует, так как функция не содержит циклов.

### Намеренная ошибка

В сломанной версии при n = 0 возвращается 1 вместо 0.

Таким образом, функция считает любое допустимое
входное число ненулевым.

### Контрпример

- Входные данные: n = 0.
- Ожидаемый результат: 0.
- Фактический результат: 1.
- Постусловие нарушено.

| Версия | Вердикт |

| broken.py | Failed |

Все программы проверены посредством выполнения Python-кода.
